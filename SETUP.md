# Setup guide (Windows + VS Code)

1. Download and extract `our_little_date_cinematic_step_by_step.zip`.
2. Open VS Code. Choose **File → Open Folder** and select the extracted folder.
3. In Extensions, install **Live Server** by Ritwick Dey if it is not already installed.
4. In the Explorer, right-click `index.html` and choose **Open with Live Server**.
5. Your browser opens the site. Click **YES**, then follow the pages for date details, dinner, songs, and the joke payment screen. Use the back buttons to change earlier choices.

## No Firebase
This project uses plain HTML, CSS and JavaScript. Your plan and love letter are stored only in your browser using local storage. There is no Firebase configuration and no real payment processing.

## If it does not open
Make sure you opened the extracted project folder, not the ZIP file. Refresh the browser after saving code changes.
