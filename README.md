# Our Little Date — Cinematic Step-by-Step Edition

A beginner-friendly romantic food-date website built with plain HTML, CSS and JavaScript. All experiences are pages/steps inside one website; no separate sites, Firebase, server, account, API key, or payment service is required.

## Features
- Step-by-step flow: invitation → name/date/time → dinner choices → song choice → joke agreement → love letter → couple quiz → date wheel → unlockable surprise → invitation → final plan.
- English-only interface, cinematic night-sky styling, falling hearts/petals and optional night mode.
- Moving NO button, food selection, date/time picker, budget, special request and place.
- Love-song links open selected YouTube videos directly, with a search fallback if a video is unavailable.
- Countdown, plan summary, WhatsApp sharing and copy controls.
- Plan and love letter saved only in local browser storage.
- The ₹499 screen is a joke; no payment is taken.

## Run on Windows
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Privacy
Nothing is uploaded to a database. Browser storage is specific to this browser/device. The invitation can be downloaded as a text file or shared through WhatsApp. Songs play on YouTube; this site does not host music. YouTube availability can vary by region, network, or account.
